# Product Overview

## Kalkulatory Nieruchomości

A comprehensive Polish real estate financial calculator platform built with modern web technologies. The application provides sophisticated financial analysis tools for the Polish property market.

## Core Features

### 1. Property Purchase Calculator (`kalkulator-zakupu-nieruchomosci`)
- Complete property purchase cost calculations
- Mortgage simulation with various parameters
- Payment schedules (equal and decreasing installments)
- Overpayment analysis
- Additional costs (PCC tax, notary fees, commissions)
- PDF report generation

### 2. Rental Profitability Calculator (`kalkulator-wynajmu`)
- ROI analysis for investment properties
- Monthly and annual cash flow calculations
- Vacancy period considerations
- Operating and management costs
- Tax optimization (flat rate vs progressive scale)
- Multi-year projections

### 3. Credit Capacity Calculator (`kalkulator-zdolnosci-kredytowej`)
- Advanced creditworthiness assessment algorithm
- Interest rate stress testing (+2.5%)
- Dynamic living costs calculation
- All financial obligations consideration
- Different employment contract types
- Budget structure visualization

### 4. Property Valuation Calculator (`kalkulator-wyceny`)
- **AI-powered Ensemble Model** (LightGBM + Random Forest + CatBoost)
- **0.79% MAPE accuracy** - highest precision in Poland
- Intelligent fallback system (Ensemble → Random Forest → Heuristic)
- Location autocomplete with Olsztyn region database
- Integration with other calculators
- 100+ advanced features

### 5. Fliper Calculator (`kalkulator-flipera`)
- Property flipping analysis
- Renovation cost calculations
- Profit margin analysis

## Target Market
